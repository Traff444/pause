# ПАУЗА — единое ТЗ для Claude Code

## 0. Результат

Собрать mobile-first PWA на русском языке для пилота постепенного сокращения курения. Это один пользователь, одно устройство, offline-first. Приложение не является медицинским изделием и не обещает оздоровление от простого сокращения. Главная задача: сначала показать реальный ритм, затем мягко увеличивать обязательную паузу между сигаретами, а после 16 недель дать человеку добровольный выбор периода без сигарет.

Не добавлять без отдельного согласования: регистрацию, чат/сообщество, рейтинг, триггеры, настроение, геолокацию, время сна, дневной лимит, ручное редактирование истории, рекламу, красные «провалы», пуш «пора курить».

## 1. Технологические требования

- React + TypeScript + Vite, PWA manifest + service worker. Допускается другой современный стек, если сохраняется вся логика ниже.
- Данные хранить локально в IndexedDB (например, Dexie); приложение полностью работает без сети. Отсутствие сети не должно блокировать отметку сигареты или выполнение активности.
- Все вычисления — чистые TypeScript-функции с инъекцией `now` и `timezone`; не размазывать бизнес-логику по UI.
- Local date считать в timezone пользователя. Смена даты происходит в локальную полночь. Не просить установить время бодрствования.
- Добавить README: запуск, сборка, структура данных, тесты, известные ограничения пилота.

## 2. Навигация и общие правила

Постоянный нижний tab bar: **Сегодня / План / Здоровье / Статистика**. Это единственные вкладки. Панель закреплена снизу и не перекрывает контент; у скроллируемых экранов нижний padding учитывает её высоту + safe area.

В шапке допускается только иконка настроек `⚙`; никаких аватаров. Награды доступны из «Плана» по карточке/ссылке «Все награды».

Любой интерактивный элемент: минимум 44×44 pt, понятный focus state, aria-label. При крупном системном шрифте карточки растягиваются, текст не обрезается. Нужны состояния loading, empty, offline, error, disabled.

## 3. Дизайн-система — обязательна

Точно соблюдать утверждённый стиль:

- фон `#F8F7F3`; текст `#050505`; основной синий `#1246B8`; вторичный серый `#6E7280`; границы `#E6E7E9`; белые карточки `#FFFFFF`;
- шрифт: **Manrope**, fallback `SF Pro Display`, `-apple-system`, sans-serif. Никаких узких/конденсированных шрифтов;
- 8-pt grid; горизонтальные отступы 24 px на 390 px экране;
- разделы: uppercase, 20–22 px, weight 700, синие; заголовки: 32–36 px, weight 700, чёрные; body 16–18 px; вспомогательный 14–16 px;
- белые карточки: radius 26 px (в списках 20–24 px), border 1 px, мягкая тень `0 8px 24px rgba(0,0,0,.07)`;
- primary-кнопка — синий круг или синий rounded rectangle, белый uppercase текст; secondary — белая pill-кнопка с чёрной подписью и тонкой границей;
- tab bar: большая синяя скруглённая панель, белые line-icons и подписи; активный icon имеет тонкое белое кольцо;
- не применять зелёный, градиенты, иллюстрации рук, рукописную графику, фото сигарет, черепа, эмодзи на главных экранах, красный как маркер ошибки.

Анимации: 180–240 ms ease-out для переходов/состояний; аккордеоны 220 ms; tap на главной круговой кнопке — scale 0.97 на 90 ms; snackbar появляется снизу над tab bar 180 ms и исчезает через 10 сек. При `prefers-reduced-motion` — убрать движение, оставить мгновенную смену состояния.

## 4. Модель данных

```ts
type Phase = 'observation' | 'reduction' | 'preparation' | 'choice' | 'quit';
type SmokingEvent = { id: string; occurredAt: string; createdAt: string; deletedAt?: string };
type Program = {
  startedAt: string; phase: Phase; timezone: string;
  baselineDailyCount?: number; baselineIntervalMinutes?: number; dailyStepMinutes?: number;
  preparationExtensions: number; quitStartedAt?: string; lastFixedTargetMinutes?: number;
};
type DailySnapshot = {
  localDate: string; phase: Phase; targetMinutes?: number;
  result?: 'success' | 'neutral' | 'repeat' | 'not_finished'; createdAt: string;
};
type Settings = { packPrice?: number; cigarettesPerPack?: number; moneyGoal?: {title: string; amount: number}; notifications: boolean };
type ActivityCompletion = { localDate: string; activityId: string; completedAt: string };
type Reward = { id: string; awardedAt: string };
```

`SmokingEvent` — единственный источник факта курения. Никогда не менять существующие `DailySnapshot.targetMinutes` из-за позднего изменения данных. В v1 нет видимой истории и нет backfill/edit.

## 5. Онбординг

Три коротких экрана в стиле приложения:

1. `ПАУЗА / ТВОЙ МОМЕНТ. ТВОЙ ВЫБОР.` — текст «Постепенный путь к жизни без сигарет» → **НАЧАТЬ**.
2. `ПОСЧИТАЕМ ТВОЮ ЭКОНОМИЮ?` — поля «Средняя цена пачки», «Сигарет в пачке»; оба необязательны; ссылка «Можно заполнить позже» → **ПРОДОЛЖИТЬ**.
3. `НАЧИНАЕМ ПУТЬ К СВОБОДЕ` — «Первые 7 дней просто отмечай каждую сигарету. Ничего не нужно менять» → **ПРОДОЛЖИТЬ**.

После третьего создать `Program(phase='observation')`, открыть «Сегодня». Не спрашивать о стаже, триггерах, сне или количестве сигарет.

## 6. Алгоритм программы

### 6.1 Наблюдение: дни 1–7

- Нажатие круга `ИДУ КУРИТЬ` немедленно создаёт событие с `occurredAt=now`; подтверждение до записи отсутствует.
- Показать snackbar: `Отмечено! ✓   ОТМЕНИТЬ`. Кнопка доступна 10 секунд и soft-delete только последнее событие, созданное этим действием.
- После 7 локальных календарных дней посчитать: `baselineDailyCount = events / 7`; `baselineIntervalMinutes` = среднее положительных интервалов внутри каждого дня **без одного самого длинного интервала этого дня**. Если в большинстве дней <2 события, продлить наблюдение максимум на 3 дня с сообщением «Нам нужно ещё немного отметок, чтобы подобрать спокойный ритм». Если данных недостаточно — оставаться в observation.

### 6.2 Сокращение: дни 8–112

- `dailyStepMinutes = clamp(round(baselineIntervalMinutes * 0.05), 2, 5)`.
- День 8: `target = baselineInterval + step`. Затем на новый день: если вчера `success`, target + step; иначе target повторяется. Цель в течение одного дня **никогда не меняется**.
- Результат: 0 сигарет = success; 1 = neutral; 2+ = success, если минимум половина фактических интервалов ≥ цели; иначе repeat. Для neutral/repeat не писать обвинительный текст.
- Неделя 16: последняя достигнутая цель фиксируется и не растёт.

### 6.3 Отказ

После дня 112 автоматически не включать quit. Открыть bottom sheet выбора:

`Ты прошёл 16 недель подготовки!` / `Какой следующий шаг выберешь?`

Кнопки: **НАЧАТЬ ПЕРИОД БЕЗ СИГАРЕТ** и **ПРОДЛИТЬ ПОДГОТОВКУ НА 7 ДНЕЙ**. Продление создаёт 7 дней `preparation` с фиксированной целью; число продлений не ограничивать. Quit запускается только по primary-кнопке.

## 7. Вкладка «Сегодня» — все состояния

### 7.1 Наблюдение

Шапка: `НАБЛЮДЕНИЕ` / `День N из 7` / справа `Осталось N дней`; одна тонкая линия прогресса N/7. Карточка: строка «Количество сигарет» + число, divider, «Последняя сигарета» + `N мин. назад`. До первой отметки сознательно показывать `0 мин. назад`.

Центр: большой синий круг `ИДУ КУРИТЬ`; ниже тонкая стрелка вверх и текст «Нажми прямо перед сигаретой.» Никакой истории на экране.

### 7.2 Сокращение и подготовка

Шапка недель 2–15: `ТРЕНИРУЕМ ПАУЗУ` / `Неделя N из 16` / `Осталось N недель`, тонкая общая линия прогресса. Неделя 16 и продление: `ГОТОВИМСЯ К ОТКАЗУ` / `Неделя подготовки` / `Финальный этап`, линия заполнена.

После последней сигареты показывать большой таймер до daily target: `До следующей паузы 08:41`, ниже `Сегодняшняя цель — 27 минут`. Пока таймер не закончился, **нет кнопки «курить»**: отображаются только поддерживающий текст «Ты уже держишь паузу» и карточка метрик дня. Это намеренное нативное подталкивание, а не наказание.

Когда таймер достиг нуля, вместо него показать две равные кнопки:

- **ИДУ КУРИТЬ** — создаёт событие мгновенно, запускает новый таймер от now;
- **ПРОПУСКАЮ** — не создаёт событие, увеличивает `skippedCount` только для UI и запускает следующий такой же интервал от now.

Если нажать «ПРОПУСКАЮ», показывать `Отлично, продолжаем паузу` и следующий таймер. Если пользователь открывает приложение после уже прошедшей цели, сразу показывать эти две кнопки. При первой сигарете дня отсчёт должен считаться от предыдущей отметки, включая вчерашнюю; если предыдущей записи нет, показать `Сегодня просто отмечай сигареты` и круг `ИДУ КУРИТЬ`.

Вечером последнего дня недели — не блокирующая карточка «Завтра начнётся новая неделя. Пауза будет расти только если текущая цель закрепилась». В первый день новой недели — bottom sheet с задачей недели, кнопками **ПОНЯТНО** и текстовой **ПОЗЖЕ**. В конце недели — тёплая полноширинная карточка с кнопкой **ПРОДОЛЖИТЬ**.

### 7.3 Quit

Шапка: `БЕЗ СИГАРЕТ` / `День N` / `N часов`, полная тонкая синяя линия. Hero: `Без сигарет уже N дней N часов`; деньги (если доступны), `Ближайшая веха: 30 дней`; primary **МНЕ СЕЙЧАС ТЯЖЕЛО**.

«Мне сейчас тяжело» открывает bottom sheet с 3-минутным обратным таймером и кнопкой **НАЧАТЬ 3 МИНУТЫ**. После него: «Ты переждал волну. Выбери, что поможет дальше» + три элемента: «5 минут разминки», «Короткая прогулка», «Вернуться на Сегодня». Не давать советов о лекарствах/диагнозах.

Отметка сигареты в quit доступна через неброскую text-button `Отметить сигарету`. После тапа сразу показать sheet: `Одна сигарета не отменяет твой путь.` / `До этого момента: N дней N часов без сигарет.` Кнопки **ВЕРНУТЬСЯ К ОТКАЗУ** (закрыть текущий период и начать новый сейчас) и **ВЗЯТЬ НЕДЕЛЮ ПОДГОТОВКИ** (на следующий день начать 7 дней fixed target). Не использовать слово «сорвался».

## 8. Вкладка «План»

Вертикальный скроллируемый roadmap. Верх: `ТВОЙ ПУТЬ`, `Неделя N из 16`, подзаголовок этапа. Затем аккордеон «Как работает путь». В раскрытии четыре строки: «7 дней наблюдаем», «пауза растёт постепенно», «сложный день не обнуляет путь», «после подготовки выберешь следующий шаг».

Ниже 16 карточек недель и карточка «После подготовки — период без сигарет». Карточки 64–72 pt в свёрнутом виде. По нажатию раскрывается одна карточка, ранее открытая сворачивается; анимация 220 ms. Прошедшие — синяя галочка; текущая — синяя обводка и раскрыта по умолчанию; будущие — серый контур, но доступны. Не блокировать будущие карточки и не указывать их будущий персональный target.

Текущая раскрытая карточка содержит: `СЕЙЧАС`, название, `Сегодня цель-пауза: N минут`, `До следующей недели: N дней`, задачу и тёплый текст. Прошедшая — задачу и похвалу. Будущая — коротко «пауза станет немного длиннее, если текущая закрепится».

Тексты недель: 1 Наблюдаем ритм; 2 Начинаем первую паузу; 3 Закрепляем новый ритм; 4 Тренируем паузу; 5 Укрепляем устойчивость; 6 Замечаем момент выбора; 7 Держим свой темп; 8 Два месяца пути; 9 Продолжаем спокойно; 10 Больше свободы в моменте; 11 Сохраняем движение; 12 Три месяца пути; 13 Готовимся к следующему этапу; 14 Закрепляем уверенность; 15 Подходим к финальной подготовке; 16 Неделя подготовки. Последняя карточка: «После подготовки — период без сигарет» + текст «Выбор всегда остаётся за тобой».

Добавить карточку `НАГРАДЫ` внизу плана. Она ведёт на отдельный scroll screen с полученными/будущими вехами: 7 дней, 30 дней, 2 месяца, 3 месяца, 16 недель подготовки, 7/14/30/90 дней без сигарет. Будущие — контурные, без замка; полученные — синие. Награда выдаётся один раз, мини-анимация scale/fade 300 ms, затем bottom sheet с тёплым текстом и **ПРОДОЛЖИТЬ**.

## 9. Вкладка «Здоровье»

Это оригинальный Apple Health-подобный dashboard только о курении и поддерживающем движении. До baseline показать заголовок `ЗДОРОВЬЕ`, карточку «Собираем твой ритм» и одну сегодняшнюю активность.

После baseline порядок:

1. Hero-card: `НЕ ВЫКУРЕНО`, `N сигарет`, `На P% меньше, чем обычно`, тонкая синяя trend-line.
2. Две карточки: `СОКРАЩЕНИЕ` / `−N пачки` / «примерно за время программы»; `СЭКОНОМЛЕНО` / `N ₽` / «P% от цели». Если цена не задана, вместо второй — CTA «Добавь цену пачки, чтобы считать экономию» → settings.
3. Широкая: `СРЕДНЯЯ ПАУЗА`, `N ч N мин`, `В начале: N минут`, тонкая прогресс-линия.
4. Карточка активности (заменяет бесполезный «Текущий этап»): `СЕГОДНЯШНЯЯ АКТИВНОСТЬ`, название, `N минут · мягкое движение`, круглая outline icon. Кнопки **ОТКРЫТЬ ВИДЕО** (внешний YouTube, заранее заданный URL) и **ГОТОВО ✓**. После готово: `Сегодня ты уделил время себе`; повторный тап спрашивает «Отметить как невыполненное?».
5. Инфо-карточка: «Каждая невыкуренная сигарета — меньше воздействия табачного дыма сегодня.»

`notSmoked = max(0, baselineDailyCount * daysSinceReductionStart - eventsSinceReductionStart)`. `savedMoney = notSmoked * (packPrice / cigarettesPerPack)`. Всегда показывать «примерно». Не показывать медицинские сроки восстановления до полного отказа.

Активности — одна на день, не влияют на серию/деньги/награды. Ротация: недели 1–4 — 5 минут; 5–8 — 10; 9–16 и quit — 15. Темы: спина и плечи, шея/грудной отдел, мягкая зарядка стоя, на стуле, лёгкая растяжка, короткая прогулка. Держать локальный каталог минимум из 5 заранее проверенных YouTube-ссылок: id, title, minutes, URL, fallback text. Не добавлять шаги, калории, воду, бытовые задачи.

## 10. Вкладка «Статистика»

Вверху segmented control: **Неделя / Месяц / Всё время**, по умолчанию «Неделя». Переключение обновляет данные с crossfade 180 ms, не меняет tab.

Порядок: главный вывод `На N сигарет меньше, чем в первую неделю`; bar chart количества сигарет (Пн–Вс/дни месяца); карточка `СРЕДНЯЯ ПАУЗА` с текущей, стартовой и сегодняшней целью; самая длинная пауза; итог «примерно не выкурено / сэкономлено». До достаточных данных: «Отмечай сигареты — здесь появится твой личный ритм». Нажатия на столбцы ничего не редактируют и не открывают историю. После quit сверху показывать текущую серию и ближайшую веху; сокращение остаётся во «Всё время».

## 11. Настройки, уведомления, ошибки

Settings: цена пачки, сигарет в пачке, цель накопления (название+сумма), timezone, разрешение уведомлений, «О приложении». Валидация: цена >0, сигарет 1–100, цель >0. Любое изменение сохранять мгновенно; корректные подтверждения snackbar.

Уведомления выключены по умолчанию. Допускаются только: вечерняя сводка, сегодняшняя активность, начало недели, итог недели. Запрещены: «пора курить», «ты не выдержал», уведомления после ранней сигареты. Если permission denied — объясняющая inline-card с кнопкой «Открыть настройки устройства», без повторяющихся диалогов.

## 12. Тесты и acceptance

Покрыть unit-тестами baseline, сон/самый длинный интервал, полночь, 0/1/2+ события, target step 2–5, success/neutral/repeat, fixed week16, неделю продления, notSmoked/money, timezone. E2E: onboarding; один tap+undo; 7 дней → reduction; недоступность «курить» до таймера; две кнопки после цели; skip запускает следующий интервал; раскрытие roadmap; activity+YouTube; edit settings; week16 choice; quit support; quit lapse flows; offline reload; large font.

Критерии готовности: все четыре вкладки соответствуют описанию; приложение offline; ни один сценарий не использует стыд/красный «провал»; будущий план полностью доступен; таймер не меняет цель внутри дня; ручной истории нет; дизайн совпадает с токенами выше на ширинах 375 и 430 px.
